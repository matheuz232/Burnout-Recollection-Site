# Burnout ReCollection — Site

Site oficial do **Burnout ReCollection**, projeto independente de preservação e recompilação dedicado aos três primeiros jogos da franquia Burnout.

## Projetos

- Burnout — `matheuz232/Burnout-Recompiled`
- Burnout 2: Point of Impact — `matheuz232/Burnout-2-Recompiled`
- Burnout 3: Takedown — `matheuz232/Burnout-3-Recompiled`

## Site

Site estático em HTML, CSS e JavaScript, publicado através do GitHub Pages.

## Aviso

Este é um projeto independente e não distribui ISOs, BIOS, músicas, vídeos, modelos, texturas ou outros conteúdos proprietários dos jogos. Cada usuário deve utilizar sua própria cópia legal.
